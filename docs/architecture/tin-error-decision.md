# TinError decision — 2026-09-30

Issue #46 is decision-only. The new exact-sample measurement reports, at the captured public reference: curvature-aware requested 8,000 points retained 7,615 with 0.013635253906272737 m maximum and 0.0013126492280712805 m RMS vertical residual; requested 4,000 retained 3,770 with 0.05400828826122961 m maximum and 0.0074652241614992535 m RMS. At the normal 15,000 budget the 12,099 valid cells all remained, so both errors are exactly zero. The same 4,000-point uniform comparison was materially worse at 0.26278076171877274 m maximum and 0.016075620270515494 m RMS, with 30 explicitly reported coverage gaps.

Decision: retain the curvature-aware simplifier. Do not open Candidate A or Candidate B implementation work from this memo. The measured default has no simplification loss on this representative reference, and the reduced-budget curvature result is already substantially better than the simple sampler. One compact reference cannot certify a general worst-case bound or settle a multi-week implementation cost.

Candidate A remains the only plausible follow-on if the owner later requires a certified bound across additional representative AOIs: it preserves exact original samples and can be designed around the same NODATA-safe coverage rule. Candidate B (geometry3Sharp QEM) is not selected: its blended interior vertices conflict with the exact-sample preference, and it would require an explicit package/version and notice decision before any implementation issue. Neither candidate is implemented or added as a dependency here.
